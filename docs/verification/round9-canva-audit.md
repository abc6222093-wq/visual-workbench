# 第 9 轮 · 以 Canva 为标准的交互审核表

审核标准（用户）：**即便只保留工作台，也能完成大部分操作。** 凡是 Canva 里「在画布上直接做」的事，工作台里也应该能直接做，而且顺滑、不闪、不卡。

审核方法：逐个读 `web/app.js`、`web/render.js`、`web/page-views.js`、`web/editor-hit-test.js`、`web/appearance-controls.js`、`web/context-menu.js` 的实际行为，对照 Canva 网页版的通用习惯；结论写在动手改代码之前（第 9 轮开工时，基于第 8 轮最终提交 `8fc59b1`）。

「本轮」一列：**处理** = 本轮做完并有测试；**不处理** = 写明理由；**不做** = 用户在第 8 轮明确不要（隐藏页面、页面标题、跳到第几页、复制/粘贴样式、图层上下移/置顶置底、对齐到页面、编组/取消编组快捷键、图层顺序快捷键、Alt 拖出副本、Shift 等比缩放、画布缩放快捷键、空格平移画布、标尺和手动参考线）。

## 1. 画布上的选择与移动

| 项目 | Canva 里怎么做 | 工作台现在 | 差距 | 本轮 |
|---|---|---|---|---|
| 单击选中 | 点元素 | 能（holder 捕获阶段挑元素，锁定的点不中） | 无 | — |
| Shift 加选 / 减选 | Shift+点 | 能 | 无 | — |
| 拖框多选 | 空白处拖框 | 能（第 8 轮） | 无 | — |
| 点空白取消选择 | 点画板空白或画板外 | 能（拖框距离 ≤2px 视为点击，清空） | 无 | — |
| Esc | 退出组内选择 → 取消选择 | 能 | 无 | — |
| 拖动移动 + 吸附 | 拖动，边缘/中线吸附 | 能，Alt 临时关闭吸附 | 无 | — |
| **松手后画面** | 不闪 | **闪一下**：松手后 `renderBoard()` 整块画板重建、所有图片节点重建，属性栏整块重建 | 明显 | **处理**（B1、B3） |
| 悬停提示 | 鼠标经过元素出现细描边 | 没有 | 不知道点下去会选中谁 | **处理**：悬停细描边（锁定元素不显示） |
| 组内选择 | 点组 → 再点进入组内 | 能（第二次点击进入） | 无 | — |
| 方向键微移 | 1px / Shift 10px | 能，连续按合并一次撤销 | 无 | — |

## 3. 文字

| 项目 | Canva | 工作台现在 | 差距 | 本轮 |
|---|---|---|---|---|
| **就地编辑** | 双击文字出现光标，直接改 | **不能**，只能去属性栏的文本框或大纲里改 | 最大的差距 | **处理**（C1） |
| 选中部分文字 | 鼠标拖选 | 不能（画布上） | 同上 | **处理**（C1） |
| 换行 | Enter | 只能在属性栏文本框 | 同上 | **处理**（C1） |
| 中文 / 日文输入法 | 选字过程中不打断 | 属性栏文本框正常；画布上无编辑 | — | **处理**：组合输入中不提交、Esc/Enter 留给输入法（C1） |
| 结束编辑 | 点空白 / Esc | — | — | **处理**（C1） |
| 一次编辑一条撤销 | 是 | 属性栏文本框**每打一个字记一条撤销** | 撤销粒度太细 | **处理**：画布编辑一次会话一条（C2）；属性栏文本框同一次输入合并为一条 |
| 新建文字直接编辑 | 新建后已全选占位字，直接打字替换 | 新建后只是选中 | 多一步 | **处理**（C3） |

| 右键「编辑文字」 | —（Canva 有类似入口） | 没有 | — | **处理**：文字元素右键菜单加「编辑文字」 |
| 对齐、行高、字距 | 顶部工具栏 | 格式里有（align / lineHeight / letterSpacing），**属性栏没有入口** | 只能让 agent 改 | **处理**：属性栏加「对齐」「行高」「字距」 |
| 局部文字单独设样式（一段加粗、变色） | 能 | 格式是「一个元素一种样式」 | 需改格式 | **不处理**：要改项目格式和导出/动效，牵动面大；如需要请用户决定，下一轮单独做 |
| 文字框随内容自动长高 | 能 | 文字超出框不裁切但框高不变 | 外框与内容不一致 | **不处理**：自动改高度会改动用户调过的尺寸、影响动效计算，需要她拍板（见报告「需要拍板」） |

## 11. 保存与刷新是否被察觉

| 项目 | Canva | 工作台现在 | 差距 | 本轮 |
|---|---|---|---|---|
| 自动保存 | 悄悄进行，顶部一行小字 | 每次保存「已保存 → 正在保存… → 对勾跳一下」 | 每次都能看到闪动 | **处理**（B2）：普通保存画面不变，超过 1.5 秒才显示「正在保存…」，失败/冲突立即显示 |
| 自己保存的文件被读回 | 无感 | 文件监听事件若先于保存响应到达，会当作 agent 修改整编辑器重建并弹提示 | 偶发闪 + 误提示 | **处理**（B2） |
| agent 改了项目 | — | 整编辑器重建 | 闪 | **处理**：增量更新，仍提示「已载入 agent 的最新修改」 |
| agent 换了素材文件 | — | 整编辑器重建 | 闪 | **处理**：只给受影响的图片换地址 |

## 本轮处理清单

1. B1 编辑后只更新变化的部分（移动、缩放、旋转、属性、改字、粘贴、删除、撤销重做、页面排序、换页），画板/面板/缩略图节点不换、图片不重载。
2. B2 保存安静化；自己写盘读回不刷新；agent 修改与素材替换增量刷新。
3. B3 「拖完闪一下」的复现测试（修前失败、修后通过）。
4. C1–C3 文字就地编辑（双击、部分选中、换行、输入法、Esc/点空白结束、一次会话一条撤销、大纲实时同步、新建即编辑）；选中文字按 Enter 编辑；右键「编辑文字」。
5. 属性栏文本框同一次输入合并为一条撤销。
6. D1 页面拖动插入线、让位、边缘自动滚动、「N 页」；三处一致。
7. D2 网格拖框多选；三处点空白取消选择。
8. D3 选择习惯统一：画布 / 页面区 / 总览都支持点空白取消、拖框、Shift 加选、Esc 取消。
9. 总览多选、选择条批量删除、卡片右键菜单。
10. 画布旋转把手。
11. 画布悬停细描边。
12. 图片拖放替换；属性栏「显示方式」。
13. 属性栏：文字对齐 / 行高 / 字距；矩形圆角；颜色实时预览。
14. 「形状」按钮可选矩形 / 圆形。
