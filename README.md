# 视觉工作台

一个在你自己的 Mac 上运行的设计小工具：让 AI 助手（Claude Code 或 Codex）生成课件、海报等设计，你来微调，它再接着做。所有内容都只存在本机。

## 需要什么
- macOS 或 Windows
- Node 22 或更高版本

## 安装
在本文件夹里打开终端，运行：

```
npm install
```

## 桌面应用
工作台也可以像普通软件一样用：一个兔子图标，点开就是工作台，不用开浏览器，也不用管终端窗口。

- **打开**：Windows 双击桌面上的「视觉工作台（应用）」，或在开始菜单里点「视觉工作台」；Mac 点程序坞（或「应用程序」文件夹）里的「视觉工作台」。
- **已经开着再点一次**：只会把原来的窗口叫到前面，不会开第二个。
- **关闭**：直接关掉窗口就行。关窗口就是关闭工作台，会先把修改保存好，再停下本机服务；切换电脑前等它关完、再等文件夹同步完成。
- **更新代码之后**（让 agent 执行了 `git pull`）：什么都不用做，下次打开就是新版本，应用不需要重新安装。
- 原来的双击启动文件（`launchers/` 里的那两个、桌面上原来的「视觉工作台」）照样能用。
- 安装：Windows 由 agent 运行 `desktop/install-windows.ps1`（不需要管理员）；Mac 由 agent 在本机制作后拖进「应用程序」。细节见 `docs/desktop.md`。

## 第一次打开时的安全提示
这个应用没有向苹果、微软付费登记（签名），所以从网上下载来的版本第一次打开时，系统会提醒一下。确认是自己装的就放行，只需要做一次：

- **Mac 提示「无法验证开发者」或「Apple 无法检查其是否包含恶意软件」**：先点「完成」或「取消」。然后在「应用程序」文件夹里，**右键（或按住 Control 键点一下）「视觉工作台」→ 选「打开」→ 再点「打开」**。也可以打开「系统设置 → 隐私与安全性」，往下拉，在「视觉工作台」那一行点「**仍要打开**」，再输入开机密码确认。
- **Windows 提示「Windows 已保护你的电脑」**：点提示里的「**更多信息**」，再点「**仍要运行**」。
- 在自己电脑上由 agent 制作的应用一般不会出现这些提示。

## 常用命令
- `npm start`：启动工作台并自动打开浏览器。退出时在终端按 Control + C。
- 浏览器没有打开时，打开终端显示的本地地址（默认 `http://127.0.0.1:4173`）。
- `npm start -- --port 4174`：默认端口被占用时换一个端口。
- `npm run init-data`：创建数据文件夹（默认 `~/Projects/visual-workbench-data`）。
- `npm run validate`：检查项目文件有没有问题。后面可以加项目路径，例如 `npm run validate examples/sample-deck`。
- `npm run save-version -- <项目> -m "备注"`：给项目存一个版本，随时可以回头找。
- `npm run copy-pages -- <源项目> <页码> --to <新编号>`：把某个项目的页面复制到一个新项目，素材一并复制。
- `npm run export-changes -- <项目>`：给网页项目导出「交接包」（改动清单 + 改前改后对比图）。可加 `--out <目录>` 指定放哪，`--no-images` 不出对比图。
- `npm test`：运行自带测试（一般只有开发时才用）。

## 数据放哪
以总览「数据文件夹」显示的位置为准；没有本机设置时才使用仓库 `workbench.config.json` 的默认值。里面有：
- `projects/<项目编号>/`：每个项目一个文件夹（项目文件、图片、字体、历史版本）。
- `library/`：公共素材库，所有项目都能取用（取用时会复制一份进项目，互不影响）。

## 遇到问题
先跑一下 `npm run validate`。它会用中文告诉你哪里不对。把提示原样发给 AI 助手，它就知道怎么修。

更多说明：产品基准见 `PLAN.md`，项目格式见 `docs/format.md`。

## 工作台怎么用

首页的「项目总览页」显示数据目录中的项目。点「新建项目」选择画板尺寸，或者点项目缩略图进入编辑器。

左边「页面」切换页面，拖动缩略图排序；勾选页面后可「复制到新项目」，素材和字体会一起带走。中间画布显示作品本身的颜色，右边「基础编辑」调整选中元素。按住 Shift 可选多个元素；拖动移动，右下角手柄缩放。文字、颜色、字体、层级也能在右边修改。改动自动保存，撤销和重做只记录本次打开项目后的操作。

把本地图片拖到画布，或用「素材导入」添加；图片会缩到最长边 2400 像素以内，并标记「待排版」。在「公共素材库」添加常用图片，再拖到当前画布使用；每次取用都会复制进项目。

「复制引用」把页码和元素编号复制到剪贴板，方便粘进给 agent 的指令。「存一版」保存带备注的完整快照；「版本列表」查看时间和备注。

「放映」进入全屏。点击画面或按空格 / 右方向键推进，自动步骤会接着播放；一页最后一步结束后再次推进才翻页。按 Esc 退出。动效由 agent 编写，工作台只负责播放。

agent 修改文件后，工作台定期检查文件变化并重新加载。若和未保存的编辑冲突，会保留当前编辑并提示处理，避免静默覆盖。

**网页项目**：用来对已有网页做小调整（挪位置、放大缩小、改字、改色），不改原网站。总览「导入 HTML / 网页」选「网页」，可以选本地网页文件 / 文件夹 / 压缩包，或每行贴一个网址；每个网页会导入成电脑端、手机端各一页（只读取，不登录、不提交、不点击；需要登录的页面会跳过并列出来）。也可以新建网页项目自己摆。画布是一个电脑或手机大小的窗口，用鼠标滚轮上下浏览整页，看到哪里就在哪里改；拖到窗口边缘会自动滚动。导航栏、卡片这些组件是一个个分组：选中后拖动是整组移动，点一下再松开才进入组里改单个元素。选中分组、多选或全选后拖四角，就整体按比例放大缩小（字号、描边、圆角、间距一起变），也可以在画布上方的快捷工具条里输入「整体缩放 %」。想多试几版颜色：右键「复制为变体…」，再点工具栏「并排对比」，看中哪份点「选定这一份」，其余一键删掉。改好后在导出弹窗选「交接包」，会生成大白话的改动清单和改前改后对比图，用里面的「复制给agent.txt」交给写网站的 agent 去改真正的网站。

示例项目：`examples/sample-deck/` 是课件示例；`examples/sample-web/` 是网页项目示例，同一个首页分电脑端（1440×2400）和手机端（390×3000）两页，各有一个按原网页定位的导航栏分组。


## 在新电脑上安装
给协助安装的 agent：安装 Node.js 24 LTS（https://nodejs.org/）和 Git，从本仓库 GitHub 地址克隆代码，进入仓库执行 `npm ci`，再执行 `npx playwright install chromium`。Mac 和 Windows 都使用相同的仓库与项目格式。运行 `npm test`、`npm run validate` 确认安装。仓库是公开的，提交不要带真实邮箱：每个新克隆都执行一次 `git config user.email 312362635+abc6222093-wq@users.noreply.github.com`（只设这个仓库，不改全局），作者名用 GitHub 用户名即可。

Mac 双击 `launchers/启动视觉工作台.command`；Windows 双击 `launchers/启动视觉工作台.cmd`。启动器以自身所在仓库为准，不写死用户名或克隆路径。已经运行该仓库就打开浏览器，旧工作台或其他程序占着 4173 时识别进程后结束并重启当前仓库；失败会给中文提示。启动终端关闭前先按 Control+C 正常退出。

总览页点「数据文件夹」，粘贴本机已有数据目录的完整路径并保存，关闭工作台后重新启动。必须包含 projects、library/assets、library/fonts；设置不会替你创建或搬动项目。新建空数据目录可由 agent 显式执行 `npm run init-data -- --data-dir <目录>`，先确认用户所需位置。配置在用户主目录 `.visual-workbench/config.json`，所有克隆共用，不进 git。命令行、环境变量、本机配置、仓库配置依次优先；界面显示实际使用的是哪一级，没有本机配置时继续使用原仓库配置。

## 两台电脑共用（Google Drive）
两台都安装 Google Drive 桌面版，把同一份数据目录同步到本机；选择可离线使用，等待所有文件下载完成。两台本地路径可以不同，分别在工作台设置数据文件夹。代码仍通过 GitHub 更新，用户数据不能放进代码仓库。安装时不擅自移动已有数据或修改旧设置，迁移由用户另行授权。

一次只在一台电脑开工作台。换电脑前按 Control+C 停止并等 Drive 同步完成；另一台也先等同步完成再启动。数据根目录 `.workbench-sessions/` 记录电脑名称、开始和更新时间，每 15 秒更新，90 秒未更新视为过期。新鲜标记出现时，页面提示哪台电脑还开着，确认前服务端阻止项目读写；过期提示后正常进入，正常退出清除自己的标记。启动后每 5 秒检查后来同步到的标记。

普通文件同步有延迟，离线的两台机器不能互相立刻发现，因此这不是强制分布式锁。提示后应先关闭另一台并等同步，不要把「继续使用」当成允许同时编辑。打开项目发现 `project (1).json`、冲突副本等会列出名字，不自动删文件或合并；请 agent 对比并先存版。

大纲的复制说明可选择「请填大纲」或「请排版」，再选当前页/全部页。填大纲说明留有文档粘贴/路径位置：先只填文案和草稿文字，用户改好后再发排版说明。

Windows 启动入口 `.cmd` 只有 ASCII 字符和 CRLF 换行，中文提示集中在带 UTF-8 BOM 的 PowerShell 文件里；PowerShell 5 按 BOM 读脚本，并把控制台与管道输出设为 UTF-8，因此不依赖中文/日文系统的默认代码页。可复现检查：在中文或日文 Windows，把仓库放进含中文、日文和空格的路径，双击启动；再次双击应只打开浏览器；关闭终端后再启动应无新鲜占用提示。缺少 Node 的机器会保留窗口显示中文下载提示。
