# 视觉工作台

一个在你自己的 Mac 上运行的设计小工具：让 AI 助手（Claude Code 或 Codex）生成课件、海报等设计，你来微调，它再接着做。所有内容都只存在本机。

## 需要什么
- macOS 或 Windows
- Node 22 或更高版本

## 安装
在本文件夹里打开终端，运行：

```
npm install
```

## 桌面应用
工作台也可以像普通软件一样用：一个兔子图标，点开就是工作台，不用开浏览器，也不用管终端窗口。

- **打开**：Windows 双击桌面上的「视觉工作台（应用）」，或在开始菜单里点「视觉工作台」；Mac 点程序坞（或「应用程序」文件夹）里的「视觉工作台」。
- **已经开着再点一次**：只会把原来的窗口叫到前面，不会开第二个。
- **关闭**：直接关掉窗口就行。关窗口就是关闭工作台，会先把修改保存好，再停下本机服务；切换电脑前等它关完、再等文件夹同步完成。
- **更新代码之后**（让 agent 执行了 `git pull`）：一般什么都不用做，下次打开就是新版本。只有 `desktop/` 里的应用壳本身改了（例如第 12 轮修正加的右键菜单）才需要重新制作并替换应用；应用是旧版本时工作台顶部会提示。
- 原来的双击启动文件（`launchers/` 里的那两个、桌面上原来的「视觉工作台」）照样能用。
- 安装：Windows 由 agent 运行 `desktop/install-windows.ps1`（不需要管理员）；Mac 由 agent 在本机制作后拖进「应用程序」。细节见 `docs/desktop.md`。

## 第一次打开时的安全提示
这个应用没有向苹果、微软付费登记（签名），所以从网上下载来的版本第一次打开时，系统会提醒一下。确认是自己装的就放行，只需要做一次：

- **Mac 提示「无法验证开发者」或「Apple 无法检查其是否包含恶意软件」**：先点「完成」或「取消」。然后在「应用程序」文件夹里，**右键（或按住 Control 键点一下）「视觉工作台」→ 选「打开」→ 再点「打开」**。也可以打开「系统设置 → 隐私与安全性」，往下拉，在「视觉工作台」那一行点「**仍要打开**」，再输入开机密码确认。
- **Windows 提示「Windows 已保护你的电脑」**：点提示里的「**更多信息**」，再点「**仍要运行**」。
- 在自己电脑上由 agent 制作的应用一般不会出现这些提示。

## 常用命令
- `npm start`：启动工作台并自动打开浏览器。退出时在终端按 Control + C。
- 浏览器没有打开时，打开终端显示的本地地址（默认 `http://127.0.0.1:4173`）。
- `npm start -- --port 4174`：默认端口被占用时换一个端口。
- `npm run init-data`：创建数据文件夹（默认 `~/Projects/visual-workbench-data`）。
- `npm run validate`：检查项目文件有没有问题。后面可以加项目路径，例如 `npm run validate examples/sample-deck`。
- `npm run save-version -- <项目> -m "备注"`：给项目存一个版本，随时可以回头找。
- `npm run copy-pages -- <源项目> <页码> --to <新编号>`：把某个项目的页面复制到一个新项目，素材一并复制。
- `npm run edits -- <项目>`：看这个项目的修改单（agent 用）；`--clear` 清掉。
- `npm run convert -- <项目>`：把旧格式（v2）项目转换成新格式（打开项目时也会自动做）。
- `npm run export -- <项目> --html --images --pdf --web`：导出（`--web` 线上浏览版、`--print` 印刷版；`--pptx` PPTX 图片版、`--pptx-editable` PPTX 可改字版）。
- `npm run export-changes -- <项目>`：导出「交接包」（改动清单 + 改前改后对比图）。可加 `--out <目录>` 指定放哪，`--no-images` 不出对比图。
- `npm test`：运行自带测试（一般只有开发时才用）。

## 数据放哪
以总览「数据文件夹」显示的位置为准；没有本机设置时才使用仓库 `workbench.config.json` 的默认值。里面有：
- `projects/<项目编号>/`：每个项目一个文件夹（项目文件、图片、字体、历史版本）。
- `library/`：公共素材库，所有项目都能取用（取用时会复制一份进项目，互不影响）。

## 遇到问题
先跑一下 `npm run validate`。它会用中文告诉你哪里不对。把提示原样发给 AI 助手，它就知道怎么修。

更多说明：产品基准见 `PLAN.md`，项目格式见 `docs/format.md`。

## 工作台怎么用

首页是「项目总览」，显示数据文件夹里的项目。右上角三个按钮：「复制给 agent」（从零开始做设计 / 请整理文件夹）、「导入旧项目」（旧 HTML 课件或网页）、「新建项目」（选画板尺寸，或「从文案开始」）。左边边栏除了总览、素材库、更换背景，还有「回收站」和「数据文件夹」（鼠标停在图标上显示名字）。点项目缩略图进入编辑器。

### 总览
- **排序**：按住项目卡片或文件夹拖动，拖到两张卡片之间（出现一条竖线）就排到那里，顺序会记住；文件夹里的项目也能排。
- **文件夹**：和电脑里的文件夹一样用。点卡片最后的「＋ 新建文件夹」；文件夹是一个玻璃文件夹，里面露出前几个项目的缩略图。把项目卡片拖到文件夹正中（文件夹整个亮起来）就放进去，或右键「移到…」（选中几个一起移）；点文件夹进去，点标题里的「项目总览」回来，把项目拖到「项目总览」上就移出。文件夹右键可以重命名、删除（删除文件夹不删项目，项目回到总览）。agent 整理过文件夹以后，顶栏有「退回整理前」，一键恢复。agent 新建项目用「日期 + 简短名」命名。
- **设计卡片**：鼠标放到项目卡片上，角上出现小图标，表示 agent 写过设计卡片（方向名、概念、配色、字体、特征）。点开能看，「复制给 agent」可以交给别的项目当风格参考。
- **拖进来导入**：HTML 文件、网页文件夹、`.zip` 拖到总览上松手，就导入成新项目；`.md` / `.txt` 文案拖进来，按草稿分页新建项目。

### 在页面上改
每一页是 agent 写好的网页。agent 标出来能动的地方（文字、图片、色块），鼠标移上去会出现边框。
- **选中**：点一下选中，出现框和把手。点空白处或按 Esc 取消。
- **改字**：先选中文字，**再点一下（或直接双击）**出现光标，像 Word 一样打字、选字、复制粘贴；按 Esc 或点旁边结束。改字号、改颜色：选中后在画布上方的小工具条里改。
- **多选**：按住 Shift 或 Cmd（Windows 是 Ctrl）再点，加选或去掉；在空白处按住拖一个框，框到的都选上；Cmd/Ctrl+A 全选这一页。
- **移动**：选中后按住拖；方向键一次挪 1 像素，按住 Shift 一次挪 10 像素。选了几个就一起挪。
- **改大小**：拖四个角是等比缩放，文字的字号跟着一起变；拖四条边只改宽或高。
- **删除**：选中后按 Delete，或右键「删除」。可以撤销（Cmd/Ctrl+Z）。删掉的东西只是先藏起来，agent 下一轮会把它正式去掉、顺手调好版面。
- **对齐**：选中两个以上，工具条上会出现 6 个对齐按钮（左、水平居中、右、顶端、垂直居中、底端）。
- **裁切图片**：双击图片。**贴图**：复制一张截图，在画布上按 Cmd/Ctrl+V，之后可以拖动、缩放、裁切、删除。
- 带多屏动效的页面，画布下方有「第 1 屏」「第 2 屏」……点哪个，画面就停在那一屏播完的样子，照常修改。编辑时点击不会播放动效。

这些修改都记在这一页的「修改单」里，叠在页面上显示，不改 agent 写的页面。改动自动保存；撤销、重做只管这次打开项目以后的操作。

### 批注和画笔
改不了的地方交给 agent。
- **批注**：工具条点「批注」，在页面上拖一个框，写一句话按回车。框可以拖动、改大小、双击改字。
- **画笔**：点「画笔」，随手画线、箭头、圈出地方，可以选颜色；画好的线能点选、拖动、配一句话。
- 批注和画的线选中后按 Delete 或右键「删除」，可以撤销。它们只在编辑时显示，放映和导出里没有。

### 交给 agent
点右侧「复制给 agent」，有四项：**请处理修改单**（把你的修改正式做进设计）、**请设计**（把草稿页做成正式页面）、**请统一风格**（把从别的项目拼进来的页改成和本项目一致）、**请整理文件夹**。有批注的页会先截一张带批注编号的图，一起交给 agent，所以要多等几秒。复制后开新的 agent 对话粘贴就行。

### 草稿分页
拿到一份分好页的文案（`#` 项目名、`## Page 1 ｜ 封面` 或 `---` 分页、【核心信息】上页面、【辅助信息】【动效】给 agent 看、「大标题：」等开头是层级提示），在总览「新建项目 → 从文案开始」粘贴，或把 `.md` / `.txt` 拖进总览；项目里也可以「添加页面 → 从文案添加草稿页…」。工作台生成白底朴素的草稿页，按真实画面大小显示，先看看字多不多。草稿页上直接打字；工具条「层级」把这一段改成大标题、小标题、正文、注释等；Cmd/Ctrl+Enter 从光标处分成两页；「和下一页合并」接上下一页；这些都可以撤销。调好后「复制给 agent → 请设计」。

### 页面整理
- 左边页面栏切换页面，有列表、时间轴、网格三种看法；拖动缩略图排序；右键加页、复制页、删页。
- **从其他项目添加页面**：「添加页面 → 从其他项目…」，选项目、勾页面、选插到哪里。页面连样式、字体、图片、修改单原样带过来；之后「复制给 agent → 请统一风格」。
- **导入为页面**：把旧的 `.html`、网页文件夹或 `.zip` 拖进页面栏，或右键「导入为页面…」。
- 「存一版」保存带备注的完整快照；「版本列表」查看、退回或删除版本。

### 放映
「放映」全屏播放：点击画面或按空格 / 右方向键推进，一页放完再推进才翻页；往回翻停在上一页的最后一步。桌面应用里放映就在应用窗口内全屏进行，按 Esc 回到原来那一页；浏览器里在新标签页放映。

### 导出
「导出」里可以选：
- **放映版 HTML**（一个文件，双击就能放映，手机也能开）、**每页图片**、**整份 PDF**。这三种都要选用途：**线上浏览版**（文件小，发给别人看、放网上）或**印刷版**（高清，拿去印刷）。
- **PPTX**：图片版（每页一张画面）或可改字版（文字能在 PowerPoint 里改）。PPTX 只用来演示，不分用途。

导出时显示「正在导出第 3 / 15 页」，可以取消；完成后告诉你文件在哪，可以一键打开文件夹。

agent 修改文件后，工作台自动重新加载；和你没保存的修改冲突时，保留你的并提示。

### 网页项目
用来对已有网页做小调整，不改原网站。总览「导入旧项目」选「网页」，选本地网页文件 / 文件夹 / 压缩包，或每行贴一个网址；每个网页导入成电脑端、手机端各一页（只读取，不登录、不提交、不点击）。画布是电脑或手机大小的窗口，滚轮上下浏览，看到哪里改哪里。改好后在导出里选「交接包」，生成改动清单和改前改后对比图，交给写网站的 agent。

### 旧项目
以前（格式 v2）做的项目第一次打开时，工作台先自动存一版再转换成新格式，看起来和原来一样；转换失败会提示，项目原样不动。更早做的项目打开时也会先存一版，再自动补上「文字、图片、色块都能移动缩放」的标记，只补标记不动设计。

**常用字体库**：站酷小薇、思源宋体（简 / 日）、思源黑体（简 / 日）这 5 套完整字体放在数据文件夹的 `library/fonts/`，让 agent 运行一次 `npm run fonts -- install` 就装好。页面用到这 5 套时，改字打出 agent 没嵌进去的字也能正常显示；导出时只保留用到的字。别的字体缺字时，用批注告诉 agent。

示例项目：`examples/sample-deck/` 是课件示例；`examples/sample-web/` 是网页项目示例。

## 在新电脑上安装
给协助安装的 agent：安装 Node.js 24 LTS（https://nodejs.org/）和 Git，从本仓库 GitHub 地址克隆代码，进入仓库执行 `npm ci`，再执行 `npx playwright install chromium`。Mac 和 Windows 都使用相同的仓库与项目格式。运行 `npm test`、`npm run validate` 确认安装。仓库是公开的，提交不要带真实邮箱：每个新克隆都执行一次 `git config user.email 312362635+abc6222093-wq@users.noreply.github.com`（只设这个仓库，不改全局），作者名用 GitHub 用户名即可。

Mac 双击 `launchers/启动视觉工作台.command`；Windows 双击 `launchers/启动视觉工作台.cmd`。启动器以自身所在仓库为准，不写死用户名或克隆路径。已经运行该仓库就打开浏览器，旧工作台或其他程序占着 4173 时识别进程后结束并重启当前仓库；失败会给中文提示。启动终端关闭前先按 Control+C 正常退出。

点左边边栏的「数据文件夹」，粘贴本机已有数据目录的完整路径并保存，关闭工作台后重新启动。必须包含 projects、library/assets、library/fonts；设置不会替你创建或搬动项目。新建空数据目录可由 agent 显式执行 `npm run init-data -- --data-dir <目录>`，先确认用户所需位置。配置在用户主目录 `.visual-workbench/config.json`，所有克隆共用，不进 git。命令行、环境变量、本机配置、仓库配置依次优先；界面显示实际使用的是哪一级，没有本机配置时继续使用原仓库配置。

## 两台电脑共用（Google Drive）
两台都安装 Google Drive 桌面版，把同一份数据目录同步到本机；选择可离线使用，等待所有文件下载完成。两台本地路径可以不同，分别在工作台设置数据文件夹。代码仍通过 GitHub 更新，用户数据不能放进代码仓库。安装时不擅自移动已有数据或修改旧设置，迁移由用户另行授权。

一次只在一台电脑开工作台。换电脑前按 Control+C 停止并等 Drive 同步完成；另一台也先等同步完成再启动。数据根目录 `.workbench-sessions/` 记录电脑名称、开始和更新时间，每 15 秒更新，90 秒未更新视为过期。新鲜标记出现时，页面提示哪台电脑还开着，确认前服务端阻止项目读写；过期提示后正常进入，正常退出清除自己的标记。启动后每 5 秒检查后来同步到的标记。

普通文件同步有延迟，离线的两台机器不能互相立刻发现，因此这不是强制分布式锁。提示后应先关闭另一台并等同步，不要把「继续使用」当成允许同时编辑。打开项目发现 `project (1).json`、冲突副本等会列出名字，不自动删文件或合并；请 agent 对比并先存版。

Windows 启动入口 `.cmd` 只有 ASCII 字符和 CRLF 换行，中文提示集中在带 UTF-8 BOM 的 PowerShell 文件里；PowerShell 5 按 BOM 读脚本，并把控制台与管道输出设为 UTF-8，因此不依赖中文/日文系统的默认代码页。可复现检查：在中文或日文 Windows，把仓库放进含中文、日文和空格的路径，双击启动；再次双击应只打开浏览器；关闭终端后再启动应无新鲜占用提示。缺少 Node 的机器会保留窗口显示中文下载提示。
